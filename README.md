# Week 3 Database Assignment

## Overview
This assignment demonstrates the fundamentals of SQL database management using MySQL. It focuses on creating a database table, inserting records, retrieving data, and updating existing records.

## Learning Objectives
- Understand how to create a database table using `CREATE TABLE`.
- Define columns and data types.
- Set a primary key.
- Insert records using `INSERT INTO`.
- Update existing records using `UPDATE`.
- Retrieve records using `SELECT`.

## Table Structure

The assignment uses a table named `student` with the following columns:

| Column | Data Type | Description |
|---|---|---|
| id | INT | Unique student identification number |
| fullName | VARCHAR(100) | Student's full name |
| age | INT | Student's age |

The `id` column is the primary key.

## SQL Operations Performed

### 1. Creating the Student Table
Created a table named `student` with three columns: `id`, `fullName`, and `age`.

### 2. Inserting Student Records
Inserted the following student records:

- John Kamau — 19 years
- Mary Wanjiku — 18 years
- Peter Otieno — 21 years

### 3. Updating Student Information
Updated Mary's age from 18 to 20 using an SQL `UPDATE` statement.

### 4. Retrieving Records
Used the `SELECT` statement to display and verify the student records.

## Final Result
The assignment successfully demonstrated basic SQL table creation, data insertion, data retrieval, and data modification.

Mary Wanjiku's age was successfully updated to 20.
